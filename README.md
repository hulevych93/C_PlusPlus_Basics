# Основи програмування на C++

Матеріали факультативу для тих, хто ніколи не програмував: презентації, код, написаний на заняттях, і задачі з очікуваним виводом.

## Мета курсу

Навчитися розкладати задачу на кроки, записувати їх кодом і самостійно знаходити помилки.

Курс не ставить за мету вивчити весь C++. Він дає навичку, яку далі можна розвивати в будь-якій мові.

## Як побудований курс

- **Одне заняття на тиждень, 60 хвилин, онлайн.** Одна ідея на заняття.
- **Задача тижня у двох рівнях:** «для тих, хто починає» і «для тих, хто вже вміє». Рівень обирає слухач і може змінювати його щотижня. Дедлайн — початок наступного заняття.
- **Перевірка через тести.** Кожна задача має очікуваний вивід. Розв'язок правильний, коли вивід програми збігається з ним посимвольно.

## Як працювати із задачею

1. Відкрийте `praktyka/zadachi.md` або файл `task_*.cpp` потрібної задачі.
2. Напишіть розв'язок усередині `main` у файлі задачі.
3. Скомпілюйте й запустіть:

   ```
   g++ -std=c++17 task_1a.cpp -o task_1a
   ./task_1a
   ```

   На Windows замість `./task_1a` запускайте `task_1a.exe`.

4. Порівняйте вивід з очікуваним для кожного рядка таблиці тестів.

Потрібні компілятор C++ з підтримкою C++17 (`g++` або `clang++`) і редактор — на заняттях використовуємо VS Code з розширенням C/C++.
