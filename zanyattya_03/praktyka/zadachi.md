### 3f. Знайти помилку
Програма у файлі `task_3f.cpp` має виводити `zero`, якщо введене число дорівнює нулю, і `not zero` в усіх інших випадках. Вона компілюється, але для будь-якого числа виводить `not zero`. Знайти й виправити помилку.

```cpp
int n = 0;
std::cin >> n;

if (n = 0) {
    std::cout << "zero\n";
} else {
    std::cout << "not zero\n";
}
```

| Вхід | Вихід після виправлення |
|---|---|
| `0` | `zero` |
| `5` | `not zero` |
| `-3` | `not zero` |
