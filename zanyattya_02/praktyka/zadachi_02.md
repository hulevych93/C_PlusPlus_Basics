# Заняття 2. Задачі

## Тема 1. Ділення цілих

### 2a. Тижні в році
У році 365 днів. Вивести два числа через пробіл: кількість повних тижнів і кількість днів, що лишились.

Вхідних даних немає.

```
52 1
```

### 2b. Остача
Ввести ціле число. Вивести остачу від його ділення на 2.

| Вхід | Вихід |
|---|---|
| `7` | `1` |
| `8` | `0` |

### 2c. Хвилини й секунди
Ввести кількість секунд. Вивести два числа через пробіл: повні хвилини і секунди понад них.

| Вхід | Вихід |
|---|---|
| `1000` | `16 40` |
| `59` | `0 59` |

## Тема 2. Дробові числа

### 2d. Піца
Поділити 8 шматків піци на 3 осіб. Вивести результат ділення одним числом з дробовою частиною.

Вхідних даних немає.

```
2.66667
```

### 2e. Точність
Вивести результат перевірки `0.1 + 0.2 == 0.3`. Потім вивести значення `0.1 + 0.2` із 17 значущими цифрами.

Вхідних даних немає.

```
0
0.30000000000000004
```

### 2f. Обрізання й округлення
Перетворити `2.99` на ціле число двома способами: через `static_cast<int>` і через `std::lround`. Потім те саме для `0.29 * 100`.

Вхідних даних немає.

```
2
3
28
29
```

## Задача тижня

Обирається один рівень. Дедлайн — початок заняття 3.

### 2g. Рахунок · рівень «для тих, хто починає»
Ввести суму рахунку (дробове, `≥ 0`), відсоток чайових (ціле, від 0 до 100) і кількість людей (ціле, `≥ 1`). Вивести суму, яку платить кожен, рівно з двома знаками після крапки. Програма не виводить нічого, крім цього числа.

| Вхід | Вихід |
|---|---|
| `450 10 3` | `165.00` |
| `1000 15 4` | `287.50` |
| `99.99 0 1` | `99.99` |
| `100 12 7` | `16.00` |
| `35 10 3` | `12.83` |

### 2h. Решта · рівень «для тих, хто вже вміє»
Ввести два дробові числа: ціну покупки і суму, яку дав покупець. Обидва мають не більше двох знаків після крапки, сума не менша за ціну. Вивести решту у форматі `Г грн К коп`.

| Вхід | Вихід |
|---|---|
| `12.50 20` | `7 грн 50 коп` |
| `0.80 1` | `0 грн 20 коп` |
| `1.35 2` | `0 грн 65 коп` |
| `73.40 100` | `26 грн 60 коп` |
| `99.99 100` | `0 грн 1 коп` |
