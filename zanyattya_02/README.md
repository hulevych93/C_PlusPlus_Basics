## Що вивчаємо

- ділення цілих чисел `/` відкидає дробову частину, а не округлює
- остача `%` і пара `/` + `%` для розкладання на одиниці: тижні й дні, хвилини й секунди
- введення з клавіатури: `std::cin >>`
- тип `double` для дробових чисел
- тип результату ділення визначають операнди, а не змінна, куди він записується
- дробове число в пам'яті — наближення: `0.1 + 0.2` не дорівнює `0.3`
- вивід із заданою кількістю знаків: `std::fixed`, `std::setprecision`
- `static_cast<int>` обрізає, `std::lround` округлює

## Головна ідея заняття

Комп'ютер ділить не так, як ми звикли. Ділення цілих відкидає дробову частину, а дробове число в пам'яті — лише наближення до справжнього.

Обидва ефекти тихі: компілятор не попереджає, програма просто рахує інше число. Тому перед запуском варто знати, яку відповідь ви очікуєте.

## Наступне заняття

Умови: програма вибирає, що робити, залежно від даних.
