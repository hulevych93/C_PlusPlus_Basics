# Заняття 1. Задачі

## Тема 1. Вивід на екран

### 1a. Сходинки
Вивести три рядки: один символ `*`, два символи `*`, три символи `*`.

Вхідних даних немає.

```
*
**
***
```

### 1b. Візитка
Вивести три рядки: ім'я, назва групи, улюблена страва.

Вхідних даних немає.

```
Ivan Petrenko
KN-11
Borscht
```

### 1c. Діалог
Вивести три репліки діалогу, по одній на рядок. У коді кожну репліку підписати коментарем із іменем того, хто говорить.

Вхідних даних немає.

```
- Did you finish the homework?
- Almost. One task left.
- Send it when you are done.
```

### 1d. Секунди в добі
Обчислити кількість секунд у добі й вивести одним числом.

Вхідних даних немає.

```
86400
```
