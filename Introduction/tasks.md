## Тема 1. Вивід на екран

### 1. Сходинки
Вивести три рядки: один символ `*`, два символи `*`, три символи `*`.

Вхідних даних немає.

```
*
**
***
```

### 2. Візитка
Вивести три рядки: ім'я, назва групи, улюблена страва.

Вхідних даних немає.

```
Ivan Petrenko
KN-11
Borscht
```

### 3. Діалог
Вивести три репліки діалогу, по одній на рядок. У коді кожну репліку підписати коментарем із іменем того, хто говорить.

Вхідних даних немає.

```
- Did you finish the homework?
- Almost. One task left.
- Send it when you are done.
```

## Тема 4. Умови

### 12. Залік
Ввести бал. Якщо бал не менший за 60 — вивести `Passed`. Інакше не виводити нічого.

| Вхід | Вихід |
|---|---|
| `75` | `Passed` |
| `40` | *(порожньо)* |
| `60` | `Passed` |

### 13. Квиток
Ввести два числа: ціну квитка і наявну суму. Якщо грошей вистачає — вивести `Enough`. Інакше вивести `Need N more`, де N — різниця.

| Вхід | Вихід |
|---|---|
| `200 150` | `Need 50 more` |
| `200 200` | `Enough` |

### 14. Оцінка ECTS
Ввести бал від 0 до 100. Вивести літеру за шкалою: від 90 — `A`, від 82 — `B`, від 74 — `C`, від 64 — `D`, від 60 — `E`, менше 60 — `F`.

| Вхід | Вихід |
|---|---|
| `95` | `A` |
| `85` | `B` |
| `50` | `F` |

### 15. Прогулянка
Ввести два числа, кожне 0 або 1: чи йде дощ, чи зроблена домашка. Вивести `Yes`, якщо дощу немає і домашка зроблена. Інакше вивести `No`.

| Вхід | Вихід |
|---|---|
| `0 1` | `Yes` |
| `1 1` | `No` |
| `0 0` | `No` |

### 16. Файл на флешці
Ввести два числа: розмір файлу і вільне місце. Зберегти результат порівняння у змінну типу `bool` і вивести її.

| Вхід | Вихід |
|---|---|
| `100 500` | `1` |
| `900 500` | `0` |
